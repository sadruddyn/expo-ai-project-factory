# Approval prompts

## Start planning

Use the `expo-project-factory` skill. Analyze this project and prepare the full plan. Do not modify files, install dependencies, or run destructive commands. Wait for my approval.

## Approve one phase

Approved. Implement Phase [N] only. Before adding dependencies or changing native configuration, explain the change. After implementation, run the relevant checks and report exact results.

## Review only

Use the `expo-project-factory` skill in audit-only mode. Do not modify files. Report architecture, compatibility, security, performance, accessibility, and testing findings, prioritized by severity.
